# Category backgrounds

Generated with the built-in image_gen tool, then encoded as 1200 px WebP assets. Blur and motion are applied in CSS, not baked into the files.

## Prompt set

Shared direction: one landscape 3:2 background for a technology store category card; full bleed; realistic cinematic editorial photography; moderate contrast and softly lit central area for an overlaid 3D product; recognizable scene details throughout; no border, collage, watermark, added typography or foreground product mockup.

- `friends.webp`: Candid gathering of five young adult friends at an outdoor café table in Córdoba, Argentina, laughing naturally at golden hour in a leafy courtyard. Wide environmental composition.
- `university.webp`: University lecture hall during class, adult students seen from behind with notebooks, professor near a whiteboard, natural daylight from tall windows. Documentary photography.
- `code.webp`: Close-up of a monitor showing Visual Studio Code in dark theme with activity bar, file tree, tabs and syntax-colored JavaScript; slight angle, dim developer workspace, blue and teal screen light. No headlines or slogans.
- `gaming.webp`: Realistic AAA-style open-world game scene, lone explorer seen from behind on a rocky path overlooking a lush mountain valley, waterfalls and monumental stone ruins, golden sun through mist. No HUD, text or weapons.
- `concert.webp`: Live concert photographed within the audience, crowd silhouettes and raised hands, distant band on stage, amber and magenta beams through haze, authentic concert atmosphere.
